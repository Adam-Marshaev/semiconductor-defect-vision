# Semiconductor Defect Vision System

End-to-end computer vision and ML engineering project for semiconductor
defect analysis using scanning-electron-microscope (SEM) imagery.

## Planned workflow

1. Dataset validation and exploratory analysis
2. Classical OpenCV segmentation baseline
3. CNN-based modeling
4. U-Net semantic segmentation
5. Transformer-based segmentation comparison
6. Rigorous evaluation and error analysis
7. Production-style inference pipeline
8. NVIDIA Tesla V100 FP32/FP16 benchmarking

## Dataset

Primary dataset: Carinthia-S

The dataset contains semiconductor SEM defect imagery with expert-validated
binary segmentation masks.

Dataset files are not stored in this repository.

## Hardware

Development and GPU benchmarking are performed on an NVIDIA Tesla V100
SXM2 32GB.
