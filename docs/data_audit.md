The dataset is extremely class imbalanced.

achieve high raw accuracy while failing to solve the classification task.

invented.

## Mask Encoding Audit

Although the masks are semantically binary, their raw PNG representation is
not uniformly restricted to pixel values `{0, 255}`.

Observed:

- 3,970 masks contain exactly two values `{0, 255}`
- 226 masks contain one value and are all-black
- 395 masks contain intermediate grayscale intensity values
- all masks remain 480 x 480

Non-binary grayscale masks by label:

| Label | Masks with intermediate values |
|------:|-------------------------------:|
| 1 | 44 |
| 2 | 8 |
| 3 | 317 |
| 4 | 26 |
| 5 | 0 |
| 6 | 0 |

Only a very small proportion of all mask pixels use intermediate grayscale
values. The dominant raw values are 0 and 255.

Threshold-sensitivity testing showed that the foreground area changes only
modestly across thresholds ranging from 1 to 254, indicating that most
intermediate values occur near annotation boundaries rather than throughout
large continuous-valued regions.

## Canonical Mask Normalization

For analysis, training, and evaluation:

1. Load the mask using Pillow.
2. Convert its storage representation to grayscale (`L`).
3. Convert to a canonical binary mask using:

   `foreground = grayscale >= 128`

4. Store the canonical mask in memory as 0/1 values.

The raw PNG masks are never modified.

Threshold 128 was selected as the midpoint of the 8-bit range after auditing
the dataset's raw mask intensities and testing threshold sensitivity.

## Known Dataset Questions

The following remain to be investigated:

- canonical semantic names corresponding to labels 1-6
- why label 6 contains 226 empty masks and one non-empty mask
- exact duplicate images
- near-duplicate / highly similar images
- possible acquisition-level grouping or leakage
- defect-area distribution by class
- connected-component distribution
- defect location within the image
- bounding-box size and aspect ratio
- intensity distributions by class
- outliers
- relationship between intermediate mask values and annotation provenance

Train/validation/test splits must not be finalized until leakage/grouping
analysis is complete.
