# Data

This directory contains local dataset files used by the project.

## Structure

- `raw/` — original downloaded dataset files. Do not modify manually.
- `processed/` — deterministic derived artifacts such as manifests, splits,
  resized images, cached metadata, or derived annotations.

Dataset files are intentionally excluded from Git.

Primary dataset:

Carinthia-S semiconductor defect SEM dataset
https://zenodo.org/records/16895427
