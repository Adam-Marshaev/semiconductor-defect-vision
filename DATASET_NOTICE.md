# Dataset Attribution

This project uses the Carinthia-S semiconductor defect dataset.

## Carinthia-S

**Title:** Carinthia-S dataset

**Creators:**
- Corinna Kofler
- Vahidin Hasić

**DOI:** https://doi.org/10.5281/zenodo.16895427

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0)

https://creativecommons.org/licenses/by/4.0/

Carinthia-S contains scanning electron microscope (SEM) images of
semiconductor defects and corresponding expert-validated segmentation masks.

The raw Carinthia-S dataset and trained model checkpoints are not distributed
in this repository.

Figures in this repository that contain or incorporate Carinthia-S SEM imagery
are derived visualizations produced during model evaluation, error analysis,
and comparison. These figures may include annotations, segmentation masks,
model predictions, crops, composites, or other modifications of the original
dataset material.

Changes to the original dataset material include, where applicable:

- image selection and cropping
- image resizing or layout composition
- overlaying segmentation masks
- overlaying model predictions
- grouping multiple samples into comparison figures
- visualization and annotation for error analysis

Carinthia-S dataset material remains subject to the CC BY 4.0 license.
No endorsement by the original dataset creators is implied.
